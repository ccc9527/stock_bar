# Stock Bar - 股票行情桌面悬浮条

一个简洁的桌面股票行情悬浮窗，实时显示A股、美股等指数价格和涨跌幅。

## 功能特性

- **实时行情显示** - 支持上证指数、沪深300、纳指、标普500等多个指数
- **自动轮播** - 每10秒自动切换显示下一个股票
- **定时刷新** - 每10分钟自动获取最新行情数据
- **置顶悬浮** - 无边框窗口固定在屏幕右下角（任务栏上方）
- **可拖动** - 按住左键可拖动窗口到任意位置
- **涨跌颜色** - 上涨显示红色（▲），下跌显示绿色（▼）
- **右键菜单** - 支持退出程序和立即刷新数据

## 使用方法

### 安装依赖

```bash
pip install PySide6 requests
```

### 运行程序

```bash
python stock_bar.py
```

### 交互操作

| 操作 | 效果 |
|------|------|
| **快速点击左键** | 切换到下一个股票 |
| **按住左键拖动** | 移动窗口位置 |
| **右键点击** | 弹出菜单（退出/刷新） |

## 自定义配置

在 `stock_bar.py` 中可以修改以下配置：

### 修改股票代码

```python
# 第15行
self.stock_codes = ["sh000001", "sz399300", "sh513000", "us.INX", "us.NDX", "sh513310"]
```

### 修改刷新频率

```python
# 第40行 - 数据刷新间隔（毫秒）
self.data_timer.start(600000)  # 10分钟

# 第44行 - 轮播切换间隔（毫秒）
self.display_timer.start(10000)  # 10秒
```

### 修改窗口尺寸

```python
# 第108行
self.setFixedSize(300, 38)  # 宽度, 高度
```

## 技术栈

- **PySide6** - Qt GUI 框架
- **requests** - HTTP 请求库
- **腾讯财经接口** - 行情数据来源

## 常见问题

**Q: 为什么有些股票显示不出来？**
A: 腾讯财经接口可能不支持某些股票代码，请确认代码格式正确（A股用 sh/sz 前缀，美股用 us. 前缀）。

**Q: 如何自定义底色？**
A: 修改 `update_style()` 方法中的 `background` 颜色值。
